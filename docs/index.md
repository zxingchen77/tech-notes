# 技术与研究，持续记录

这里是星辰的中文技术博客，记录 **AI 深度研究、软件工程实践、学习笔记与个人思考**。

我希望把零散的信息整理成可以回看、验证和继续完善的知识：先提出问题，再说明证据，最后讨论结论的边界和实践意义。

## 阅读方向

| 方向 | 关注的问题 |
| --- | --- |
| **AI Research · AI 研究** | 模型能力、应用场景、研究方法，以及 AI 对工作的影响 |
| **Technology · 技术实践** | 编程、系统设计、工程工具与可复现的技术经验 |
| **Learning · 学习笔记** | 学习方法、知识管理，以及从阅读到实践的过程 |
| **Thinking · 个人思考** | 对技术与日常工作的观察、反思和阶段性判断 |

在[内容分类](topics.md)中了解各方向，通过[文章列表](blog/index.md)的分类和年份导航浏览已发布内容，也可以直接使用顶部全文搜索。

## 从哪里开始

本站刚刚建立，目前仅有一篇[Markdown 写作示例](blog/posts/technology/markdown-example.md)，用于演示长文结构、代码与引用，并非正式研究成果。后续文章会在完成整理与核查后逐步发布。

## 内容约定

- **结论前置**：长文先给出核心结论，再展开推理和依据。
- **来源可追溯**：区分事实、推断与个人观点，尽可能链接原始资料。
- **允许修订**：展示发布日期与更新日期，实质修改记录原因。
- **说明 AI 参与**：标明 AI 辅助环节和人工核查状态。

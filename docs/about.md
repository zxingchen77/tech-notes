# 关于这个网站

这是由 [zxingchen77](https://github.com/zxingchen77) 维护的个人中文技术博客，用于沉淀 AI 深度研究、技术实践、学习笔记与经过整理的知识文档。

## 写作与核查

AI 可以参与检索线索整理、提纲和文字编辑，但 AI 输出本身不是事实依据。涉及研究结论的文章应注明 AI 参与方式、人工核查范围和参考资料；没有完成核查的内容应明确标注。

当前建站示例和维护文档由 AI 辅助编写，工程验证与作者人工内容审阅是两个独立环节，不将自动构建通过表述为研究事实已核实。

## 反馈与维护

发现错误或希望补充资料，欢迎在 [GitHub Issues](https://github.com/zxingchen77/tech-notes/issues) 中提出。引用本站内容时请注明文章标题和链接。本站暂未授予统一的开放内容许可；第三方材料的权利归原作者。

## 网站实现

网站使用 MkDocs Material 与 GitHub Pages，文章以 Markdown 保存，推送后由 GitHub Actions 自动构建。没有加入广告、评论服务或访问统计，正文阅读无需登录。
